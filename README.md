# Personal Portfolio Website

A modern full-stack personal portfolio website built to showcase my projects, technical skills, achievements, and experience.

## 🚀 Features

* Responsive and modern UI
* Project showcase section
* Skills and technologies section
* Contact section
* Interactive frontend design
* Full-stack architecture
* Database integration for storing project details
* Fast and optimized deployment

---

## 🛠️ Tech Stack

### Frontend

* HTML
* CSS
* JavaScript
* React.js
* Vite

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Deployment

* Vercel

---

## 📂 Project Structure

```bash
PersonalPortfolioWebsite/
│
├── src/                 # Source code
├── public/              # Public assets
├── components/          # Reusable UI components
├── styles/              # CSS and theme files
├── package.json         # Dependencies and scripts
├── vite.config.ts       # Vite configuration
└── README.md
```

---

## ⚡ Installation & Setup

### Clone the repository

```bash
git clone https://github.com/AP24110010657/PersonalPortfolioWebsite.git
```

### Navigate into the project folder

```bash
cd PersonalPortfolioWebsite
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```
